# Sacrifice One Pizza – Static Charity Website

## 1. Overview

**Product Name:** Sacrifice One Pizza
**Type:** Static Charity Website (Phase 1 – MVP)
**Primary Goal:** Enable people to donate the cost of one pizza per month (₹300–₹1000) via UPI QR code to support education and essential needs for underprivileged individuals.

### Core Idea

> “What if one pizza a month could change someone’s life?”

Instead of spending ₹300–₹1000 on one casual outing, donors can redirect that amount to support someone’s education, food, or basic needs.

### 5. Donation Section (Core Feature)

## Donate One Pizza 🍕

### Payment Method:

- UPI QR Code (Primary method)

### QR Code Section Requirements:

- Large scannable QR code
- UPI ID displayed below QR
- Copy button for UPI ID
- Clear donation amount suggestions

### Donation Amount Options:

- ₹300 – Basic Support
- ₹500 – Education Essentials
- ₹700 – Monthly Assistance
- ₹1000 – Full Support

Note:
The QR code remains the same; donors manually enter amount in UPI app.

### CTA Buttons:

- “I Donated ❤️”
- “Share This Mission”

Optional microcopy:

> After donating, take a screenshot and share it with us.
